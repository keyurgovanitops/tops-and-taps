1. Project Objective
Develop a complete, responsive, secure, and production-ready SaaS-based Home Services Booking Platform using AI-powered Vibe Coding tools.
The platform will connect customers with professional home service providers such as electricians, plumbers, AC technicians, cleaners, painters, carpenters, and appliance repair professionals.
The application should allow customers to discover services, book appointments, track service requests, make payments, and provide reviews. Service providers should be able to manage their services, availability, bookings, and earnings.
The trainer must use AI tools such as ChatGPT, Claude, Cursor, AntiGravity, or similar tools to plan, design, develop, test, debug, and deploy the application. The project must cover the complete Software Development Life Cycle (SDLC).
2. Business Case Study
A company named "HomeServe Technologies" wants to launch a SaaS-based home services booking platform. Currently, customers find electricians, plumbers, cleaners, and other technicians through local contacts and phone calls. This creates several problems:
Customers cannot easily find verified service providers.
Service providers struggle to find new customers.
Booking appointments manually is time-consuming.
Customers cannot track service request status.
Payment records are difficult to maintain.
Service providers cannot manage their daily schedules.
Business owners cannot monitor bookings and revenue.
Business Goal
The company wants to develop a centralized online platform to solve these problems. The platform should support multiple service providers and customers with a centralized Admin dashboard.

Phase 7: Security Implementation
The application must follow basic web application security practices.
TASKS
Hash passwords using bcrypt or Argon2.
Never store plain-text passwords.
Implement JWT authentication securely.
Apply Role-Based Access Control.
Ensure customers can access only their own bookings.
Ensure providers can access only their assigned bookings.
Ensure technicians can access only assigned jobs.
Validate and sanitize user inputs.
Prevent SQL injection using ORM and parameterized queries.
Apply CORS restrictions.
Validate uploaded file types and sizes.
Protect sensitive API endpoints.
Implement rate limiting on sensitive endpoints.
Use HTTPS in production.
Store API keys and secrets in environment variables.
Avoid exposing sensitive information in error messages.
Verify payment gateway callbacks or webhooks securely.
Prevent unauthorized payment status modification.
Implement secure password reset functionality.
